## Features

### ✅ Clickable User Mentions
Every user is tagged with @mention - click to see their profile!

### ✅ Clear Ranking
- 🥇 Gold medal for 1st place
- 🥈 Silver medal for 2nd place
- 🥉 Bronze medal for 3rd place
- **#4**, **#5**, etc. for other ranks

### ✅ Simple Layout
Each entry shows:
1. Rank (medal or number)
2. User mention (clickable)
3. Tag indicator (🏷️ if they have HDRX tag)
4. Voice time on next line with └ connector

### ✅ Easy to Read
- No complex tables
- No confusing symbols
- Clean spacing
- Clear hierarchy

### ✅ All Information Visible
- Total active members
- Current page / total pages
- Legend explaining icons
- Navigation instructions

## How to Use

### View Leaderboard
```
/topusers
```
Shows top 10 users (page 1)

### Navigate Pages
```
/topusers page:2    (Ranks 11-20)
/topusers page:3    (Ranks 21-30)
```

## What Each Symbol Means

- 🥇 = 1st place
- 🥈 = 2nd place
- 🥉 = 3rd place
- **#4** = 4th place and below
- 🏷️ = User has HDRX tag
- ⏱️ = Voice time
- └ = Connects rank to time
